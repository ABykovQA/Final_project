# Итоговый проект: задание
Тебе предстоит автоматизировать пользовательские сценарии для учебного сервиса Доска объявлений с помощью UI‑тестов. Документации к фронту или бэку у тебя нет ― есть только работающий интерфейс и список бизнес-сценариев. Используй свои навыки работы с DevTools, Selenide и Cucumber, чтобы протестировать ключевые пользовательские функции.
## Что нужно сделать
1. Исследуй поведение UI  
Используя DevTools и ручное исследование интерфейса, определи:
* какие действия и API запускают какие изменения;
* как генерируются данные;
* какие элементы участвуют в сценарии.
2. Подготовь проект
Создай Maven-проект. Назови его Final_project.  
Используй:  
* Selenide ― для взаимодействия с UI,
* RestAssured ― для подготовки данных (регистрация пользователей через API),
* Cucumber ― для описания тестов на Gherkin,
* JUnit 5 ― как тест-раннер,
* Allure ― для генерации отчётов.
3. Покрой автотестами следующие сценарии:

|    Функциональность     | Что проверить |
|:-----------------------:|:------------------------------------------:|
|       Регистрация       | Успешная регистрация с уникальным email. Попытка зарегистрироваться повторно |
|       Авторизация       | Авторизация ранее зарегистрированного пользователя |
|   Создание объявления   | 	Успешное создание объявления в любой категории |
|     Редактирование      |  Успешное редактирование своего объявления |
|        Удаление         | Успешное удаление своего объявления |
## Требования к проекту
* Тесты должны быть написаны на Java 11.
* Все автотесты оформлены в виде BDD-сценариев на Gherkin.
* Для каждого сценария есть реализация шагов на Java (Step Definitions).
* В тестах используется Selenide.
* Тесты запускаются через JUnit 5.
* Все шаги разделены по классам, при необходимости используется внедрение зависимостей (PicoContainer).
* Локаторы вынесены в Page Object или переиспользуемые методы.
* Генерация тестовых данных организована централизованно ― либо через отдельные классы, либо через утилиты, используемые повторно.
* Создание тестовых пользователей осуществляется через API ― до выполнения UI-сценариев.
* Генерируется отчёт Allure.
* Все тесты независимы.
## На что особенно обратить внимание
* Не хардкодь локаторы в каждом шаге ― используй переиспользуемые элементы и Page Object.
* Убедись, что каждый feature-файл отражает поведение системы, а не технические детали.
